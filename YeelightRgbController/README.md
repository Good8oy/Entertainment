# Yeelight 精确色卡

一个不依赖 Yeelight 色盘位置的 Android 本地控制器。它保存 RGB（每个通道 0–255）与亮度（1–100%）为命名色卡；点击色卡后会直接向灯发送相同的参数。

## 使用

1. 在 Yeelight 官方 App 中选择对应设备，打开右上角“更多”中的“局域网控制”。
2. 让手机与灯连接到同一个 Wi-Fi。
3. 安装本应用后点击“搜索局域网灯”；若没有发现，在路由器的设备列表中找到灯的 IPv4 地址并手动填入。
4. 点击“测试连接”，填写 RGB 和亮度，然后点击“保存为色卡”。以后点击对应色卡即可恢复同一组参数。

程序会先开灯，再立即设置 RGB，最后设置亮度。数值在设备端使用 Yeelight 的 `set_rgb` 和 `set_bright` 本地协议执行。

## 构建与安装

用 Android Studio 打开本文件夹，等待 Gradle 同步完成，再选择 **Build > Build APK(s)**。调试 APK 默认输出在：

`app/build/outputs/apk/debug/app-debug.apk`

本工作区已经验证过 `assembleDebug` 构建。

## 限制与安全

- 本程序只控制处于相同局域网、且启用了“局域网控制”的 Wi-Fi Yeelight 灯。
- 局域网控制协议没有传输加密；请使用可信的家庭 Wi-Fi，避免将灯暴露在公共或访客网络。
- 相同 RGB 与亮度会让设备接收相同参数；灯珠老化、环境光与灯具差异仍可能带来轻微的视觉差异。
