# 米家色盘助手

一个为米家灯具准备的 Android 辅助工具。它不登录米家、不读取账户或控制设备接口，而是保存米家色盘上的命名点击位置；以后从无障碍悬浮按钮选择色卡，即可重复点击相同位置。

## 使用

1. 在系统设置中启用本应用的“米家色盘助手”无障碍服务。首次启用后，屏幕右侧会出现“色卡”悬浮按钮；可长按拖动，避开米家色盘。
2. 在米家打开目标灯的“颜色”页面并截取完整屏幕截图。
3. 回到本应用，点击“从米家截图校准色点”，选择截图并精确点选色盘中的目标位置，输入名称后保存。
4. 使用时，手动回到同一灯的“颜色”页面，点击“色卡”悬浮按钮并选择预设。

应用仅在检测到米家位于前台且页面存在“颜色 / 色温 / color”标签时才发送手势；截图和预设仅保存在手机本地。

## 手动 RGB 与亮度

1. 在本应用的“手动 RGB 与亮度”中输入 `R`、`G`、`B`（均为 0–255）与亮度（1–100），然后保存。
2. 用完整米家截图完成两项校准：色盘矩形的左上/右下角，以及亮度滑杆的 0%/100% 位置。亮度滑杆可以是水平或垂直的。
3. 在米家同一灯的颜色页面点击悬浮“色卡”，选择“应用手动 RGB”。

程序把 RGB 转换为 HSV：色相映射到色盘横向位置、饱和度映射到纵向位置，另将亮度数值映射到已校准的米家亮度滑杆。因此，RGB 输入描述的是颜色，亮度字段描述米家灯的输出强度。

## 构建与安装

用 Android Studio 打开本文件夹，等待 Gradle 同步完成，再选择 **Build > Build APK(s)**。调试 APK 默认输出在：

`app/build/outputs/apk/debug/app-debug.apk`

本工作区已经验证过 `assembleDebug` 构建。

## 限制与安全

- 这是对米家界面的重复点击，并不是设备端 RGB 指令；它保证相同米家色盘位置，而不是绝对 RGB 数值。
- 校准截图必须是同一台手机、同一屏幕方向下的完整截图。更改显示大小、字体、米家 UI 版本或色盘布局后，应重新校准。
- 执行期间系统会将手势视为用户触摸，并可能取消正在进行的真实触摸；请先停止手动操作。
- 无障碍服务只用于本应用的色盘快捷操作，不会读取或上传米家账户、设备或截图内容。
