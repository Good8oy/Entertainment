# 米家 RGB 找色助手

一个为米家灯具准备的 Android 辅助工具。它不登录米家、不读取账户或控制设备接口；使用时截取当前米家颜色页，在用户校准的色盘矩形内寻找目标 RGB 像素并点击。

## 使用

1. 在系统设置中启用本应用的“米家色盘助手”无障碍服务。首次启用后，屏幕右侧会出现“找色”悬浮按钮；可长按拖动，避开米家色盘。
2. 在米家打开目标灯的“颜色”页面并截取完整屏幕截图。
3. 回到本应用，点击“从米家截图校准色盘区域”，依次点色盘矩形的左上角和右下角。
4. 输入目标 RGB（每项 0–255）并保存。
5. 使用时，手动回到同一灯的“颜色”页面，点击“找色”悬浮按钮并选择“识别并点击目标 RGB”。

应用仅在检测到米家位于前台且页面存在“颜色 / 色温 / color”标签时才发送手势。运行时只扫描并点击已校准的矩形；若最佳像素的任一 RGB 通道与目标相差超过 18，应用会停止且不点击。截图不会保存或上传。

## 构建与安装

用 Android Studio 打开本文件夹，等待 Gradle 同步完成，再选择 **Build > Build APK(s)**。调试 APK 默认输出在：

`app/build/outputs/apk/debug/app-debug.apk`

本工作区已经验证过 `assembleDebug` 构建。

## 限制与安全

- 这是对米家界面的 RGB 像素识别，并不是设备端 RGB 指令。实际颜色仍由米家色盘与灯具决定。
- 本功能需要 Android 11 或更新版本，以便无障碍服务截取当前屏幕。
- 校准截图必须是同一台手机、同一屏幕方向下的完整截图。更改显示大小、字体、米家 UI 版本或色盘布局后，应重新校准。
- 执行期间系统会将手势视为用户触摸，并可能取消正在进行的真实触摸；请先停止手动操作。
- 无障碍服务只用于本应用的色盘快捷操作，不会读取或上传米家账户、设备或截图内容。
