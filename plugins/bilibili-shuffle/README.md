# Bilibili 乱序播放

一个适用于 Chrome、Edge 等 Chromium 浏览器的 Manifest V3 扩展。在 Bilibili 播放页识别分 P、UP 主合集、番剧选集及 /list/{mid} 播单列表，提供手动随机跳转，并在当前视频播放结束后自动随机播放尚未播放过的条目。合集和分 P 通过 Bilibili 视频详情接口读取，UP 主播单通过 Bilibili 播单接口读取；页面链接作为回退来源。

## 安装

1. 下载或克隆此仓库，在浏览器地址栏打开 chrome://extensions（Edge 使用 edge://extensions）。
2. 打开“开发者模式”，选择“加载已解压的扩展程序”。
3. 选择本目录：plugins/bilibili-shuffle。
4. 打开 Bilibili 的视频、合集或番剧播放页，点击扩展图标开启乱序播放。

启用后，页面右下角会显示列表识别状态。一个播放周期内会尽量避免重复；播放完所有条目后开始新一轮。设置会保存在浏览器扩展的本地存储中，播放进度记录在当前标签页会话中。

## 支持范围

- Bilibili 视频分 P（/video/BV… 或 /video/av…，使用 p 参数区分分 P）。
- 创作者播单页面（/list/{mid}），按页面当前排序读取整份播单并保留播单上下文随机跳转；超过 2,000 条时随机范围最多取 2,000 条，面板会显示加载数和总数。
- 播放页内可见的合集/播放列表和番剧选集链接（/bangumi/play/ep…、/bangumi/play/ss…）。
- B 站单页应用内的地址变化和播放器视频元素替换。

列表识别依赖 Bilibili 页面当前公开的链接和 DOM。若页面布局调整后扩展提示找不到列表，可刷新页面再试；无列表的单视频页不会自动跳到推荐视频。
接口读取失败时，面板会提示当前仅使用页面已经加载的条目；同一视频在播单中重复出现时只计一次。

## 权限

- 开启扩展时会请求 api.bilibili.com 读取当前视频的分 P、合集或播单条目。
- storage：保存用户的开关状态。
- activeTab：扩展弹窗读取当前标签页并发送即时开关消息。
- Bilibili 页面访问权限：读取播放页内的列表链接并监听视频播放结束事件。
